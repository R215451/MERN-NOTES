```bash
npm install package_name
```

Example:

```bash
npm install colors
```

---

# Why Do We Not Push node_modules on GitHub ?

Because `node_modules` contains large package files.

Instead of pushing `node_modules`, we push:

```bash
package.json
```

Other developers can install packages using:

```bash
npm install
```

# What is Nodemon in Node.js ?

Nodemon keeps the server in running state.

It automatically restarts the server when code changes.

Install:

```bash
npm install -g nodemon
```

Run:

```bash
nodemon filename.js
```

# Example Server in Node.js

```js
let http = require("http");

let port = 4700;

http
  .createServer((req, res) => {

    res.writeHead(200, { "Content-Type": "text/html" });

    res.write(`
      <html>
      <head>
        <title>Node Js</title>
      </head>

      <body>
        <h3>This is Server</h3>
        <h3>${port}</h3>
      </body>

      </html>
    `);

    res.end("This is server end");

  })

  .listen(port, () => {

    console.log(`Server running at ${port}`);

  });
```

# How to Create Basic APIs Using Static Data ?

```js
let http = require("http");

let port = 4700;

const data = [

  {
    name: "Kavin",
    city: "Kota",
  },

  {
    name: "Sam",
    city: "Pune MH",
  },

  {
    name: "Peter",
    city: "Delhi",
  },

];

http
  .createServer((req, res) => {

    res.writeHead(200, {
      "Content-Type": "application/json",
    });

    res.write(JSON.stringify(data));

    res.end();

  })

    console.log(`Server running at ${port}`);

  });
```

# How to Read HTML File Data in Node.js ?

Using File System (`fs`) module.

```js
readFile('html path', 'utf-8', (err, data) => {

})
```

---

# Example

```js
const fs = require('fs');

http
  .createServer((req, res) => {

    fs.readFile('html/web.html', 'utf-8', (err, data) => {

      if (err) {

        res.writeHead(500, {
          "content-type": "text/plain"
        });

        res.write('Internal Server Error');

        res.end();

        return;
      }

      res.writeHead(200, {
        "content-type": "text/html"
      });

      res.write(data);

      res.end();

    });

  })

  .listen(port, () => {

    console.log(`Server running at ${port}`);

  });
```

# How to Access Form Data ?

## data event

Receives form data chunk-by-chunk.

```js
data_array.push(chunk)
```

Stores all chunks in array.

---

## end event

Triggers when all data is received.

```js
Buffer.concat(data_array).toString()
```

Converts chunks into readable string.

---

```js
queryString.parse(rawData)
```

Converts form data into object.

---

# Example

```js
else if (req.url === "/submit") {

    let data_array = [];

    req.on("data", (chunk) => {

        data_array.push(chunk);

    });

    req.on("end", () => {

        let rawData = Buffer.concat(data_array).toString();

        let response = queryString.parse(rawData);

        console.log(response);

        res.write("Form Successfully Submitted..");

        res.end();

    });

}
```

# How to Create File Using Sync Method ?

```js
let rawData = Buffer.concat(data_array).toString();

let response = queryString.parse(rawData);

console.log(response);

let result =
`My name is ${response.name} and email is ${response.email}`;

console.log(result);

fs.writeFileSync(`text/${response.name}.txt`, result);

console.log('File Created..');
```

---

# How to Create File Using Async Method ?

```js
fs.writeFile(
    `text/${response.name}.txt`,
    result,
    'utf-8',

    (error) => {

        if (error) {

            res.end('Internal server error');

            return;

        } else {

            console.log('File Created..');

        }

    }
);
```

# Sync Method Example

```js
const fs = require('fs');

let res = fs.readFileSync(
    'text/kunal.txt',
    'utf-8'
);

console.log(res);

console.log('End Script');
```

---

# Async Method Example

```js
const fs = require('fs');

fs.readFile(
    'text/kunal.txt',
    'utf-8',

    (error, data) => {

        if (error) {
            return;
        }

        console.log(data);

    }
);

console.log('End Script');
```

# How Does Node.js Work ?

## 1. Call Stack

Executes synchronous code.

---

## 2. Node APIs

Handles async operations.

Examples:

- File System
- Timers
- HTTP

---

## 3. Event Loop

Moves completed callbacks from callback queue to call stack.

Also called:

- Callback Queue
- Event Queue
