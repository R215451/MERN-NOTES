# ___>>> What is Database ??

A database is a structured collection of data that stores information in an organized way.

It helps to:
- retrieve data easily
- manage data
- update data efficiently

---

# Types of Database

| Type | Example |
|---|---|
| Relational Database | MySQL, SQL Server |
| NoSQL Database | MongoDB |

---

# ___>>> MongoDB

MongoDB is a:

```txt
NoSQL Database
```

MongoDB stores data in:

```txt
JSON Format
```

# ___>>> How to Install MongoDB ??

---

# Step 1 → Download MongoDB

Download:

- MongoDB Community Server
- MongoDB Compass

From:

```txt
https://www.mongodb.com/try/download/community
```

---

# Step 2 → Install MongoDB

During installation:

✅ Select:

```txt
Complete Setup
```

---

# Step 3 → Install MongoDB Compass

Compass is GUI tool for MongoDB.

It helps to:
- view databases
- create collections
- insert documents
- visually manage MongoDB

---

# Step 4 → Set Environment Variable

Add MongoDB `bin` path into Environment Variables.

Example:

```txt
C:\Program Files\MongoDB\Server\8.3\bin
```

---

# Step 5 → Verify Installation

Open CMD and run:

```bash
mongod --version
```

and

```bash
mongosh
```

---

# Important

| Command | Purpose |
|---|---|
| mongod | Starts MongoDB server |
| mongosh | MongoDB shell/client |
| Compass | GUI tool |

# ___>>> How to Insert Record ??

## Syntax

```js
db.collection_name.insertOne({
   key:value
})
```

---

# Example

```js
db.employees.insertOne({
   name:'alisha',
   department:'texttile design',
   salary:45000
})
```

---

# Output

```js
{
  acknowledged: true,
  insertedId: ObjectId('6a0ee3e04536c1b4fecd7ccd')
}
```

---

# ___>>> To Get All Records from Collection

## Syntax

```js
db.collection_name.find()
```

---

# Example

```js
db.employees.find()
```

---

# Output

```js
{
  _id: ObjectId('6a0ee3e04536c1b4fecd7ccd'),
  name: 'alisha',
  department: 'texttile design',
  salary: 45000
}
```

---

# ___>>> To Get Specific Record

```js
db.employees.find({
   name:'alisha'
})
```

---

# Output

```js
{
  _id: ObjectId('6a0ee3e04536c1b4fecd7ccd'),
  name: 'alisha',
  department: 'texttile design',
  salary: 45000
}
```

---

# ___>>> MongoDB Operators

## Greater Than Operator

```js
$gt
```

means:

```txt
Greater Than
```

---

# Example

```js
db.employees.find({
   salary:{
      $gt:15000
   }
})
```

---

# Output

```js
{
  name: 'kunal',
  department: 'autocad design',
  salary: 50000
}
```
