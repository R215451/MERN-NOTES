# 📌 app.get()

```js
app.get(path, callbackFunction)
```

## Parameters

| Parameter | Description |
|---|---|
| path | Route path |
| callbackFunction | Function that runs on request |

---

## callbackFunction Parameters

```js
(req,res,next)
```

| Parameter | Description |
|---|---|
| req | Request Object |
| res | Response Object |
| next | Middleware Function |

# 📄 How to render HTML file in Express Js ??

Use:

```js
sendFile()
```

and pass:

```txt
Absolute Path
```

---

## Example

```js
const express = require('express');
const path = require('path');

const app = express();

app.get('',(req,res)=>{

    let absPath = path.resolve('./pages/home.html');

    console.log(absPath);

    res.sendFile(absPath);

});

app.listen(1007);
```

---

# 🚫 How to show 404 Page ??

Paste this code at the last.

```js
app.use((req,res)=>{

    res.status(404).sendFile(absPath+'/404.html')

});
```

# 📂 How to load static file in Express Js ??

```js
let path_static = path.resolve('public');
```

It will return path upto:

```txt
public
```

---

## Use Static Middleware

```js
app.use(express.static(path_static));
```

This helps to load:

- CSS Files
- JS Files
- Images
- Fonts
- Videos
- Other Static Assets
