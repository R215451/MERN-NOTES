
# How to Import Module in Node.js ?

Using `require()` method:

```js
require('module_name')
```

Example:

```js
let http = require('http');
```

# What Do You Think About REPL ?

We can run code directly on the terminal.

**REPL** stands for:

- **Read**
- **Evaluate**
- **Print**
- **Loop**

It reads the input, evaluates it, prints the result, and waits for the next input.

# How to Export and Import Data in Node.js ?

## Export

```js
const add = (num1, num2) => {
    return num1 + num2;
}

module.exports = { add };
```

---

## Import

```js
let { add } = require('./data');

let response = add(10, 70);

console.log(response);
```

# Create Server in Node.js

```js
let http = require("http");

let port = 4700;

http
  .createServer((req, res) => {

    res.writeHead(200, { "Content-Type": "text/html" });

    res.write("<h2>Node Js</h2>");

    res.end("This is server end");

  })
  .listen(port, () => {

    console.log(`Server running at ${port}`);

  });
```

---

# Can We Create 2 Servers in a File ?

Yes ✅

But the **PORT** should be different for each server.

Example:

```js
let http = require('http');

http.createServer((req, res) => {
    res.end("First Server");
}).listen(3000);

http.createServer((req, res) => {
    res.end("Second Server");
}).listen(4000);
```
