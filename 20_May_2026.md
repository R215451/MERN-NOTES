# ___>>>> What do you think about MVC Architecture with Node Js ??

## MVC → Model View Controller

MVC is a design pattern used to organize application code.

| Part | Purpose |
|---|---|
| Model | Handles database or data |
| View | Displays data to user |
| Controller | Bridge between Model and View |

---

# MVC Flow

```txt
Client Request
      ↓
Controller
      ↓
Model (Data)
      ↓
Controller
      ↓
View (EJS)
      ↓
Response to Client
```

# Model File

## model/usersModel.js

```js
const usersList = ()=>{
    return ['Moin','Kunal','Asfi'];
}

export default usersList;
```

---

# Controller File

## controllar/usersControllar.js

```js
import usersList from "../model/usersModel.js"

const userControllarList = (req,res)=>{

    // Fetch data from Model
    let user_list = usersList()

    // Send data to View
    res.render('users.ejs',{
        userList:user_list
    })

}

export default userControllarList;
```

---

# Main Server File

## index.js

```js
import express from 'express'

import userControllarList from './controllar/usersControllar.js';

const app = express()

app.set('view engine','ejs');

app.get('/users',userControllarList);

app.listen(3200);
```

# ___>>> How to Create Dynamic Route ??

## Syntax

```js
app.get('/user/:name',(req,res)=>{

})
```

Dynamic route receives data from URL.

Example:

```txt
/user/moin
/user/kunal
```

---

# Dynamic Route Example

```js
app.get('/user',(req,res)=>{

    const users = ['moin','kunal','asfi'];

    let data = `<ul>`;

    for (let index = 0; index < users.length; index++) {

        data =
        data +
        `<li>
            <a href = "user/${users[index]}">
                ${users[index]}
            </a>
        </li>`

    }

    let a_tag =
    `<a href = '/user'>Back to home</a>`

    data =
    data +
    `</ul>` +
    a_tag

    res.send(data)

})
```

---

# Access Dynamic Route

```js
app.get('/user/:name',(req,res)=>{

    let data =
    `This is ${req.params.name} page..`;

    let a_tag =
    `<a href = '/user'>Back to home</a>`

    let response =
    data +
    `<br/>` +
    a_tag;

    res.send(response)

})
```

```js
app.get('/employee',(req,res)=>{

    console.log(user_data);

})
```

---

# Get Employee By ID

```js
app.get('/employee/:id',(req,res)=>{

    console.log(req.params.id);

    let response =
    user_data.filter((user)=>

        user.id === Number(req.params.id)

    )

    console.log(response);

    res.send(response)

})
```

---

# Get Employee By Name

```js
app.get('/employee-name/:name',(req,res)=>{

    let response =
    user_data.find((user)=>

        user.name.toLowerCase() ===
        req.params.name.toLowerCase()

    );

    res.send(response)

})
```
