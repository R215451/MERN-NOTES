# ___>>> What is Session ??

Session is a small piece of data stored on server.

It is mainly used for:
- login system
- authentication
- storing user information
- tracking users

---

# Difference Between Cookies and Sessions

| Cookies | Sessions |
|---|---|
| Stored in browser | Stored on server |
| Less secure | More secure |
| User can modify | Safer |
| Small size | Better for auth |

---

# Important

In sessions:
- actual data is stored on server
- browser only stores session id

# Use Session Middleware

```js
app.use(

    session({

        secret:'mern_secret_key',

        resave:false,

        saveUninitialized:false

    })

)
```

---

# Meaning of Properties

| Property | Purpose |
|---|---|
| secret | encrypt/sign session |
| resave | save again or not |
| saveUninitialized | create empty session or not |

# Complete Example

```js
import express from "express";

import session from "express-session";

const app = express();

app.set("view engine", "ejs");

app.use(
    express.urlencoded({
        extended: true
    })
);

app.use(

    session({

        secret: "mern_secret_key",

        resave: false,

        saveUninitialized:false

    })

);


// Home Page

app.get("", (req, res) => {

    console.log(req.session);

    console.log(req.session.name);

    res.render(
        "home.ejs",
        {
            email:req.session.email
        }
    );

});


// Login Page

app.get("/login", (req, res) => {

    res.render("login.ejs");

});


// Store Session Data

app.post("/profile", (req, res) => {

    console.log(
        "******************************"
    );

    console.log(req.body);

    // Store data in session

    req.session.name =
    req.body.name

    req.session.email =
    req.body.email

    console.log(
        'Session data ...............'
    );

    console.log(req.session);

    res.render("profile.ejs");

});


// Logout

app.get('/logout',(req,res)=>{

    req.session.destroy()

    res.send('Session Deleted')

})


// Server

app.listen(2100);
```

# How Session Works Internally ??

---

# Step 1 → User Opens Login Form

```js
app.get('/login')
```

Server renders login form.

---

# Step 2 → User Submits Form

```js
app.post('/profile')
```

Browser sends:
- name
- email

to server.

---

# Step 3 → Server Stores Session

```js
req.session.name = req.body.name
```

Session data stored on server.

---

# Session Object Example

```js
Session {

  cookie:{
    path:'/',
    _expires:null,
    originalMaxAge:null,
    httpOnly:true
  },

  name:'Dan Star',

  email:'rahul@gmail.com'

}
```

---

# Step 4 → Browser Stores Session ID

Browser stores special cookie:

```txt
connect.sid
```

This is session id.

---

# Step 5 → Browser Sends Session ID Again

On every request:

```txt
Browser → Session ID → Server
```

Server finds user session data.

---

# Step 6 → Access Session Data

```js
req.session.name
```

Output:

```txt
Dan Star
```

# ___>>> Why Sessions Are Better Than Cookies ??

✅ More Secure  
✅ Data stored on server  
✅ Better for authentication  
✅ User cannot easily modify data
