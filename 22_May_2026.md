# ___>>> How to Display Database Data in UI ??

We use:
- Express
- MongoDB
- EJS Template Engine

---

# Step 1 → Set EJS Engine

```js
app.set('view engine','ejs')
```

---

# Step 2 → Fetch MongoDB Data

```js
app.get('',async(req,res)=>{

    let db = await dbConnection();

    let data =
    await db.collection('employees')
    .find()
    .toArray();

    console.log(data);

    res.render('employee.ejs',{
        data:data
    })

})
```

---

# Step 3 → Display Data in EJS File

## employee.ejs

```ejs
<table border="1">

    <tr>
        <th>Name</th>
        <th>Department</th>
        <th>Salary</th>
    </tr>

    <% data.forEach((employee)=>{ %>

        <tr>
            <td><%= employee.name %></td>
            <td><%= employee.department %></td>
            <td><%= employee.salary %></td>
        </tr>

    <% }) %>

</table>
```

# Create Employee API

```js
app.post('/employee-add-api',async(req,res)=>{

    const {
        name,
        department,
        salary
    } = req.body;

    if (!name || !department || !salary){

        res.send({
            message:"Operation Failed",
            success:false
        })

        return false
    }

    let db = await dbConnection();

    let response =
    await db.collection('employees')
    .insertOne(req.body)

    res.send({
        message:"Success",
        success:true,
        result:response
    })

})
```

# ___>>> Delete Operation Using API

```js
app.delete('/delete-employee/:id',async(req,res)=>{

    const id = req.params.id;

    let db = await dbConnection();

    let response =
    await db.collection('employees')
    .deleteOne({
        _id:new ObjectId(id)
    })

    res.send({
        "message":"success",
        id:id,
        result:response
    })

})
```

# ___>>> Save Updated Employee Data From UI

```js
app.post('/save-employee/:id',async(req,res)=>{

    const id = req.params.id;

    console.log(id);

    console.log(req.body);

    const db = await dbConnection();

    let response =
    await db.collection('employees')
    .updateOne(
        {
            _id:new ObjectId(id)
        },
        {
            $set:req.body
        }
    )

    console.log(response);

    res.send('Success')

})
```

# MongoDB CRUD Operations

| Operation | Method |
|---|---|
| Create | insertOne() |
| Read | find() |
| Update | updateOne() |
| Delete | deleteOne() |

---

# Important MongoDB Methods

| Method | Purpose |
|---|---|
| find() | Get all documents |
| findOne() | Get single document |
| insertOne() | Insert document |
| updateOne() | Update document |
| deleteOne() | Delete document |

---

# Important Express Concepts

| Concept | Purpose |
|---|---|
| req.body | Receive request data |
| req.params | URL parameters |
| res.send() | Send response |
| res.render() | Render EJS file |
| express.json() | JSON middleware |
