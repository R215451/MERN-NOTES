# 📦 How to export function or data from one file to another file ??

## Export Function or Data

```js
module.exports = function_name;
```

OR

```js
module.exports = data;
```

---

## Import Function or Data

```js
let function_name = require('./file_path');
```

# 🛠️ How to Make CRUD Operation from CMD ??

## Example

```js
http.createServer((req, res) => {

    if (req.url === '/'){

        let input_arr = process.argv;

        let operation = input_arr[2];

        let file_name = input_arr[3];

        let content = input_arr[4];

        if (operation === 'update') {

            fs.appendFileSync(`text/${file_name}.txt`, `\n${content}`);

            console.log('File Updated..');

        }else if (operation === 'delete'){

            fs.unlinkSync(`text/${file_name}.txt`);

            console.log('File Deleted');

        }else{

            console.log('Operation not found..');

        }
    }

    res.end();

}).listen(port_number, () => {

    console.log(`Server is running at ${port_number}`);

});
```

# ⚡ Difference between writeFileSync() and writeFile()

| writeFileSync() | writeFile() |
|---|---|
| Blocking Thread | Non Blocking Thread |
| Synchronous | Asynchronous |
| Waits for operation completion | Does not wait |

# 🧩 How to inject another HTML in current HTML ??

## Placeholder

```html
{{header}}
```

---

## Node JS Code

```js
let header = fs.readFileSync("html/header.html", "utf-8");

let main_page = fs.readFileSync("html/website.html", "utf-8");

main_page = main_page.replace("{{header}}", header);

res.writeHead(200, {
    "content-type": "text/html",
});

res.end(main_page);
```

# 🔄 How does switching from one page to another work in Node Js ??

## Using Routes

```js
let header = fs.readFileSync("html/header.html", "utf-8");

if (req.url === "/") {

    try {

        let main_page = fs.readFileSync("html/website.html", "utf-8");

        main_page = main_page.replace("{{header}}", header);

        res.writeHead(200, {
            "content-type": "text/html",
        });

        res.end(main_page);

    } catch (error) {

        res.writeHead(500, {
            "content-type": "text/plain",
        });

        res.end("Internal Server Error");
    }

}
else if (req.url === "/about") {

    let page = fs.readFileSync("html/about.html", "utf-8");

    page = page.replace("{{header}}", header);

    res.writeHead(200, {
        "content-type": "text/html",
    });

    res.end(page);
}
```
