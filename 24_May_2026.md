# Important

If password contains special characters:

| Symbol | Encoded |
|---|---|
| @ | %40 |
| # | %23 |

Example:

```txt
admin@123
```

becomes:

```txt
admin%40123
```

# ___>>> What is Cookies ??

Cookies are small pieces of data stored in browser.

They are used to:
- store login information
- remember users
- authentication
- save user preferences

---

# Real Life Example

When user logs into website:

```txt
login=true
```

cookie is stored in browser.

Next time browser automatically sends cookie to server.

---

# Cookie Flow

| Step | Work |
|---|---|
| User Login | Server Creates Cookie |
| Browser Stores Cookie | Saved Automatically |
| Browser Sends Cookie | Every Request |
| Server Reads Cookie | User Authentication |

---

# ___>>> How to Set Cookies in Express Js ??

```js
res.setHeader(
```

# Complete Cookies Example in Express Js

```js
import express from "express";

const app = express();

app.set("view engine", "ejs");

// Middleware

app.use(
    express.urlencoded({
        extended: true
    })
);


// Login Page

app.get("/login", (req, res) => {

    res.render("student_form.ejs");

});


// Save Cookies

app.post("/profile", (req, res) => {

    res.setHeader(
        "Set-Cookie",
        [
            "login=true",
            `name=${req.body.name}`
        ]
    );

    res.render(
        "student_profile.ejs"
    );

});


// Read Cookies

app.get("/", (req, res) => {

    let response =
    req.headers.cookie;

    console.log(response);

    response =
    response.split(";");

    console.log(response);

    response =
    response[1]

    console.log(response);

    response =
    response.split('=')

    console.log(response);

    response =
    response[1]

    console.log(response);

    res.render(
        "student.ejs",
        {
            result:response
        }
    );

});


// Logout Route

app.get('/logout',(req,res)=>{

    res.clearCookie('login')

    res.clearCookie('name')

    res.send('Cookies Deleted')

})


// Server

app.listen(2100);
```

# Cookie Example Breakdown

---

# Step 1 → User Opens Login Page

```js
app.get('/login')
```

Server renders form.

---

# Step 2 → User Submits Form

```js
app.post('/profile')
```

Server receives username.

---

# Step 3 → Server Creates Cookies

```js
res.setHeader(
"Set-Cookie",
[
 "login=true",
 "name=Moin"
]
)
```

---

# Step 4 → Browser Stores Cookies

Browser automatically saves:

```txt
login=true
name=Moin
```

---

# Step 5 → Browser Sends Cookies

```js
req.headers.cookie
```

returns:

```txt
login=true; name=Moin
```

---

# Step 6 → Split Cookies

```js
response.split(";")
```

returns:

```js
[
 'login=true',
 ' name=Moin'
]
```

---

# Step 7 → Extract Name

```js
response[1]
```

returns:

```txt
name=Moin
```

Then:

```js
response.split('=')
```

returns:

```js
[
 'name',
 'Moin'
]
```

---

# Final Result

```txt
Moin
```
