# Middleware

Middleware is a function in Express that runs before the final route handler.

Flow:

```txt
Client → Request → Middleware → Server
```

---

# Basic Middleware Example

```js
app.use((req, res, next) => {

    console.log(req.url);

    next();

})
```

- `req` → request object
- `res` → response object
- `next()` → moves control to next middleware or route

---

# Middleware Example With Condition

```js
app.use((req, res, next) => {

    if (!req.query.age || req.query.age < 18) {

        res.send('Alert ! You can not access..');

    } else {

        next();

    }

})
```

---

# Route Middleware

Route middleware applies only on specific routes.

---

## Age Middleware

```js
const checkAge = (req, res, next) => {

    if (!req.query.age || req.query.age < 18) {

        res.send('Alert ! You Can not Access..');

    } else {

        next();

    }

}
```

---

## URL Checking Middleware

```js
const checkUrl = (req, res, next) => {

    console.log(req.url);

    next();

}
```

---

## Apply Middleware on Route

```js
app.get('/users',

    checkAge,
    checkUrl,

    (req, res) => {

        res.send('Users');

})
```

# How to Handle Error in Node.js Using Middleware ?

```js

  res
    .status(error.status || 500)
    .send('Try after some time..')

})
```

# What is Template Engine ?

A template engine is a software tool that combines:

- Static template
- Dynamic data

Syntax:

```ejs
<%= %>
```

---

# EJS Example

```js
import express from 'express';

const app = express();

const port = 3200;

app.set('view engine', 'ejs');

app.get('', (req, res) => {

    res.render(
        'home.ejs',
        {
            name: 'Peter',
            company: 'MicroSoft Pune'
        }
    )

})

app.listen(port, () => {

    console.log(`Server is running at ${port}`);

})
```
